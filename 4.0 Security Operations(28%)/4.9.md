# Log Data

```text
Logs on servers, devices, and other parts of the network hold a ton of security info.
    - Blocked and allowed traffic flows
    - Exploit attempts (from IPS)
    - Blocked URL categories
    - DNS sinkhole traffic (could point to something malicious inside the network)

All of this can be correlated with logs from other devices, usually in a SIEM.
```

## Firewall logs

```text
Firewalls see traffic going in and out of the network.
    - Source/destination IP, port numbers
    - Disposition, was the traffic allowed or blocked?

NGFW logs also show
    - The application in use
    - URLs and URL categories
    - Suspicious data or anomalies
```

## Application logs

```text
Windows - Event Viewer, Application log
Linux/macOS - /var/log

Usually rolled up into the SIEM to filter and view.
```

## Endpoint logs

```text
Laptops, desktops, phones, tablets, etc.
    - Log in / log off
    - System events and processes
    - Account changes, eg: password changes, lockouts
    - Directory services

Roll it up into the SIEM to correlate endpoint, network, and other device data.
```

## OS-specific security logs

```text
Operating systems log security events.
    - Brute force attacks
    - Changes to critical system files
    - Authentication details

eg: a service gets disabled that an admin wouldn't normally disable, that could trigger an alert.

There's a LOT of data, so only send what's important for security decisions to the SIEM.
```

## IPS/IDS logs

```text
Usually built into an NGFW now instead of standalone.

Shows known vulnerabilities and known attack types.
    - eg: Snort log showing a timestamp, alert class (SYN flood DoS), priority, source/destination IP and port.
```

## Network logs

```text
Switches, routers, access points, VPN concentrators.
    - Routing table changes
    - Authentication errors
    - Network attacks, eg: TCP SYN attack detected on a port and blocked for 60 seconds
```

## Metadata

```text
Data that describes other data, hidden inside files.
    - Email - headers show the servers it passed through, destination addresses, SPF and signature info
    - Mobile photos - device type, GPS coordinates
    - Web browser - OS, browser type, IP address
    - Documents/spreadsheets - author name, address, phone number, title
```

## Vulnerability scans

```text
Scan logs show what was found.
    - Missing firewall, antivirus, or anti-spyware
    - Misconfigurations, eg: open shares with no login, guest accounts enabled
    - Known vulnerabilities (keep scanner signatures updated)
    - Unsupported operating systems, NFS shares readable by anyone
```

## Automated reports

```text
Most SIEMs can create automated reports (built-in or third party).

Reports are useless if nobody reads them.

Big SIEMs can take a lot of processing power to create reports, so be specific about what you need.
```

## Dashboards

```text
Real-time summary you can view at a glance, often on the main screen in a SOC.
    - Customizable or predefined
    - Not long-term data, it takes too long to compile
    - eg: system status, active firewall rules, warnings, users and devices
```

## Packet captures

```text
Captures everything going across the network at the packet level.
    - Tools like Wireshark, some switches/routers/firewalls can capture too
    - Works on wired and wireless networks

Wireshark
    - Top pane - packet by packet summary (eg: an HTTP GET request)
    - Bottom pane - details of the selected frame (Ethernet, IPv4 header, TCP header, HTTP data)
```
