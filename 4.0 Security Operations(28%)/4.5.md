# Firewalls


## Network-based firewalls
```text
Firewalls are often used to traffic by port number or application.
2 common methods are Traditional vs. NGFW

It is often used to Encrypt traffic, often to VPN between sites.

Many firewalls can be used as layer 3 devices(routers)
    - Often sits on the ingress/egress of the network.
    - Network Address Traslation(NAT) is used within the network to properly route.
    - Often there is a level of dynamic routing
```

## Next-generation Firewalls(NGFW)

```text

It often works on the layer 7 (Application layer), it decides if an application is allowed to have traffic.

Can be referred to as
    - Application layer gateway
    - Stateful multilayer inspection
    - Deep packet inspection

Requires some advanced decodes
    - Every packet must be analyzed,categoried, and a security decision determined.

```

## Ports and Protocols

```text

Older traditional firewalls often didn't know what kind of traffic was passing through the network, it only understood what ports were being used.

That is why it was common for management of ports, because ports often correlated to type of traffic.

In new generation firewalls, we can actually just manage by type instead cuz we can actually see what type of application traffic it's from.

eg: Webserver would be enough in NGFW 
    tcp/80,tcp/443 would be managed on a traditional firewall
```

## Firewall rules

```text
It usually follows a logical path, top to bottom. It can either be very general or specific.(Specific rules are often at the top).

Implicit deny, most firewalls include a deny at the bottom(even if you dont add one).

Access Control Lists(ACLs)
    - Are what they are usually called and they allow or disallow traffic, grouping things by categories, source IP,Destination IP, port number, time of day, application,ect.
    
```

## Screened subnet

```text
An additional layer of security between the your and the internet.

-Public access to public resources and private data remes inaccessible.
```

## IPS rules

```text
Intrusion Prevention System, It is often integrated into an NGFW

Different ways to find malicious traffic, look at traffic as it passes by

1. Signature-based, every device has a signature.

2. Anomaly-based, build a baseline on what's normal and any unusual traffic is flagged.

Often you determine what happens when unwanted traffic appears.
    -Block,allow,send an alert, ect.

Thousands of rules is the normal, and usually rules can be customized by groups.

```
# Web Filtering


```text

This refers to control over traffic based on data within the content,
    - Url filtering, website category filtering

This if often to control outbound and inbound data (sensitive materials)

This can also be used to control inappropriate content.
    - Not safe for work
    - parental controls
```

## URL scanning

```text
This is often to allow or restrict based on URL.

This is often managed by category.
    - Auction,Hacking,Malware,Travel, Recreation,etc

THis can also be used to limit control over how the person can access the url.

Often this is integrated into a layer 7 Next generation firewall.
    - This filters traffic based on category or specific URL.
```

## Agent based 

```text

Software on each endpoint makes the filtering decision locally, managed from a central console

Works on any netwrokm whcih makes it ideal for remote and mobile users

Category lists have to be pushed to every agent regularly to stay current
```

## Proxy 

```text

This sits between user and the internet and makes request on the user's behalf, then
checks the reponse before passing it to the user.

Extra features include caching (serves repeat requests locally) and access control (by username/password or IP address)
```

## Explicit proxy vs transparent proxy

```text
Explicit: The application has to be configured with the proxy's address.

Transparent: works without any client configuration, and users don't even know it's there
```

## Forward proxy (Internal Proxy)

```text
A proxy for internal users reaching the internet
    - THe proxy and the users are both on the internal network, and the organization controls it's configuration
```

## DNS filtering

```text
The DNS server refuses to resolve known-bad domains, returning either a default IP or nothing, so the connection never happens.

Its block lists update from real-time threat intelligence, both commercial and public

Works beyond web browsing, it also blocks malware from looking up its commands and control server.
```

# Operating System Security 

## what's active directory?
```text
A database of everything on the network
    - This can include:
        -Computers
        -User Accounts
        -Files Shares
        -Printers
        -Groups
        -primarily Windows-based

It's often as a way to manage authentication, employees will often login using their AD credentials for anything.

Centralized access control, The main reason to use it is you can centeralize what every user is allowed to mess with.

Commonly used by the help desk
    - Reset passwords
    - Add and remove accounts 
```

## Within AD what is Group Policy?

```text
Group policy is a way to manage the computer and users with group policies.
    - Examples, Local and Domain Policies
    - Group Policy Management Editor

IT is usually configured on a central console and can be used to..
    - Login Scripts
    - Network COnfigurations
    - Security parameters

It's pretty comprehensive usually there is a setting for anything and everything.
```

## What is SELinux (Security-Enhanced Linux)

```text
It is often as a means to limit what processes can do on a machine.

Often its a enhanced kernel distribution of regular linux, replaces DAC.

It limits application access using security methods like least privilege and reducing the scope of an application.

It's open source, so you may look at the source code.

```
