# Firewalls


## Network-based firewalls
```text
Firewalls are often used to traffic by port number or application.
2 common methods are Traditional vs. NGFW

It is often used to Encrypt traffic, often to VPN between sites.

Many firewalls can be used as layer 3 devices(routers)
    - Often sits on the ingress/egress of the network.
    - Network Address Translation(NAT) translates private internal addresses to public addresses at the edge.
    - Often there is a level of dynamic routing
```

## Next-generation Firewalls(NGFW)

```text

It often works on the layer 7 (Application layer), it decides if an application is allowed to have traffic.

Can be referred to as
    - Application layer gateway
    - Stateful multilayer inspection
    - Deep packet inspection

Requires some advanced decodes
    - Every packet must be analyzed,categorized, and a security decision determined.

```

## Ports and Protocols

```text

Older traditional firewalls often didn't know what kind of traffic was passing through the network, it only understood what ports were being used.

That is why it was common for management of ports, because ports often correlated to type of traffic.

In new generation firewalls, we can actually just manage by type instead cuz we can actually see what type of application traffic it's from.

eg: Webserver would be enough in NGFW 
    tcp/80,tcp/443 would be managed on a traditional firewall
```

## Firewall rules

```text
It usually follows a logical path, top to bottom. It can either be very general or specific.(Specific rules are often at the top).

Implicit deny, most firewalls include a deny at the bottom(even if you dont add one).

Access Control Lists(ACLs)
    - Are what they are usually called and they allow or disallow traffic, grouping things by categories, source IP,Destination IP, port number, time of day, application, etc.
    
```

## Screened subnet

```text
An additional layer of security between you and the internet.

-Public access to public resources and private data remains inaccessible.
```

## IPS rules

```text
Intrusion Prevention System, It is often integrated into an NGFW

Different ways to find malicious traffic, look at traffic as it passes by

1. Signature-based, traffic is compared to signatures (patterns) of known attacks.

2. Anomaly-based, build a baseline on what's normal and any unusual traffic is flagged.

Often you determine what happens when unwanted traffic appears.
    -Block,allow,send an alert, etc.

Thousands of rules is the normal, and usually rules can be customized by groups.

```
# Web Filtering


```text

This refers to control over traffic based on data within the content,
    - Url filtering, website category filtering

This is often to control outbound and inbound data (sensitive materials)

This can also be used to control inappropriate content.
    - Not safe for work
    - parental controls
```

## URL scanning

```text
This is often to allow or restrict based on URL.

This is often managed by category.
    - Auction,Hacking,Malware,Travel, Recreation,etc

This can also be used to limit control over how the person can access the url.

Often this is integrated into a layer 7 Next generation firewall.
    - This filters traffic based on category or specific URL.
```

## Agent based 

```text

Software on each endpoint makes the filtering decision locally, managed from a central console

Works on any network, which makes it ideal for remote and mobile users

Category lists have to be pushed to every agent regularly to stay current
```

## Proxy 

```text

This sits between user and the internet and makes request on the user's behalf, then
checks the response before passing it to the user.

Extra features include caching (serves repeat requests locally) and access control (by username/password or IP address)
```

## Explicit proxy vs transparent proxy

```text
Explicit: The application has to be configured with the proxy's address.

Transparent: works without any client configuration, and users don't even know it's there
```

## Forward proxy (Internal Proxy)

```text
A proxy for internal users reaching the internet
    - The proxy and the users are both on the internal network, and the organization controls its configuration
```

## DNS filtering

```text
The DNS server refuses to resolve known-bad domains, returning either a default IP or nothing, so the connection never happens.

Its block lists update from real-time threat intelligence, both commercial and public

Works beyond web browsing, it also blocks malware from looking up its commands and control server.
```

# Operating System Security 

## what's active directory?
```text
A database of everything on the network
    - This can include:
        -Computers
        -User Accounts
        -Files Shares
        -Printers
        -Groups
        -primarily Windows-based

It's often as a way to manage authentication, employees will often login using their AD credentials for anything.

Centralized access control, The main reason to use it is you can centralize what every user is allowed to mess with.

Commonly used by the help desk
    - Reset passwords
    - Add and remove accounts 
```

## Within AD what is Group Policy?

```text
Group policy is a way to manage the computer and users with group policies.
    - Examples, Local and Domain Policies
    - Group Policy Management Editor

It is usually configured on a central console and can be used to..
    - Login Scripts
    - Network Configurations
    - Security parameters

It's pretty comprehensive usually there is a setting for anything and everything.
```

## What is SELinux (Security-Enhanced Linux)

```text
It is often as a means to limit what processes can do on a machine.

It's a security module built into the Linux kernel (originally from the NSA), it adds MAC on top of the normal DAC permissions.

It limits application access using security methods like least privilege and reducing the scope of an application.

It's open source, so you may look at the source code.

```

# Monitoring Data

## FIM (File Integrity Monitoring)
```text

Some files change over time and there needs to be a way to track if they've been altered. We also need a way to make sure the files that aren't supposed to change don't change.

This system is called the `FIM (File Integrity Monitoring)`

On Windows there is a program called SFC (System File Checker)
    - Replace the files with the proper verison

On linux there is a program named Tripwire which alerts you when a file has been changed.

Usually there are many host-based IPS options

```

## Data Loss Prevention (DLP)

```text
These are systems that detect sensitive data being sent across the network and can block that traffic in real time.

DLP systems can work in a couple ways 

1. On your computer,
    - Data in use, this sees data traveling to a specific pc and out
    - Often called Endpoint DLP

2. On your network,
    - Data in motion, this sees data traveling through the network
3. On your server,
    - Data at rest, this often is installed on a server for data at rest to prevent weird stuff leaking.
```

## If you're running DLP software you'll be often able to do USB blocking

```text
This is often DLP installed onto the computer to allow or deny certain tasks.

This could be preventing the use of usb slots for example.

```

## If you have cloud based infra, you might have to use cloud based DLP

```text
This is often located between users and the internet
    -Watch every byte of network traffic
    -No hardware, no software

This could be done by blocking custom defined data string that belong to data that belongs to your organization. This in effect blocks the data from being moved around to somewhere it shouldn't be allowed to.

This is also an effective way to block viruses and malware or anything traversing the network potentially.
```

## Emails are often the easiest way to extract information from an organization

```text
Email continues to be the most critical risk vector, so
often it is important to harden this using a DLP system.

The DLP can be configured to check every email inbound and outbound internal or cloud-based

It can also be used to block keywords, identify impostors, and quarantine email messages.

In terms of preventing data from leaving the organization it can also to Fake information transfers to trick the attacker.

```

# Endpoint Security

## The endpoint

```text
The endpoint is the device being used by the user(laptop, etc.),
there are so many layers to this from the applications the user uses, etc. So it's smart to take things in a layered approach, so you can layer on the security and make sure stuff gets covered.
```

## Edge vs. Access Control

```text
The edge of the network is the part of the network where the inside of the network meets the outside of the network or internet side.

Usually this is done via firewall to monitor what goes in and out of a network. This is usually managed on the firewall itself using rules that are often rarely changed.

Access Control on the other hand is more about limiting access of a certain type of data, access can be based on a bunch of rules. This could include groups,user, applications.

Access can be easily revoked or changed and thats what makes it powerful.

```

## Posture assessment

```text
A posture assessment is an assessment done usually on a BYOD to see where it stands security wise,
Malware infections,unauthorized apps,is it running antivirus, etc..


We can often use software to make an assessment and if we wanted to keep it on there.

1. Persistent agents
    - Permanently installed onto a system, updates will be required
2. Dissolvable agents
    - no install is required, often is removed when posture assessment is done
3. Agentless NAC
    - Integrated with Active Directory and checks are made during login/ logoff
```

## Endpoint detection and response(EDR)

```text
A different method of threat protection, this scales to meet the increasing number of threats.

Designed to take signatures and create behavioral analysis,machine learning,process monitoring.

Lightweight agent on the endpoint.

It provides root cause analysis and find a way to remove and prevent.

It can be automated.

```

## Extended Detection and Response (XDR)

```text
It is an evolution of EDR, it improves missed detections,false positives, and long investigation times, involve more than the endpoint.

Add network based-detection, used to investigate and respond to network anomalies.

Correlate endpoint,network, and cloud data.This makes it easier to improve detection rates and simplify security event investigations.


XDR commonly includes user behavior analytics, this includes what normal traffic looks like and you can use it to recognize a certain pattern for detection purposes.

```
