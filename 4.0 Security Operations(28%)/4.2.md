# Asset Management

## Acquisition / Procurement process

```text
Every org has a purchasing process for requesting and obtaining goods and services.

Very formal, sign-off needed.

Usually starts with a request from a user,
and includes budget information and formal approvals.

We'd need to negotiate with the suppliers for the best price for our operations.

After Negotiating, Purchase,invoice, and payment.
```

---

## Assignment/Accounting

```text
A central asset tracking system is often used to keep track of a item purchased.

The asset tracking system allows us to keep track who is in possession of what device.

We can then classify what type of asset it is, Software or physical?

Helps track taxes for the assets:

Hardware is depreciate, capital expenditure
Software doesn't depreciate, operational expenditure.

This helps inventory every asset,
and associate a support ticket with a device make and model.

It can also help with enumeration, it does this by listing all parts of an asset.

It also allows us to use asset tags,
    We can attach barcodes,RFID,organization names to the device for easy recognition.
```

## Media Sanitization

```text
If a device needs to be given to someone new, the data must be completely removed so no
data remains.

We can do this a couple ways,
but it is usually a one way trip once you delete the data its gone.

Reuse the storage media.
```

---

## Physical Destruction

```text
If we want to make sure the data is not retrieval usually we'd need to pulverize it or use
a machine to destroy it.

Another option is by using a drill/hammer if its only a few drives.

Another option is by using a strong magnet(degaussing)
it destroys the hard drive data and renders the hard drive unusable.

Incinerator is an option as well.
```

---

## Certificate of Destruction

```text
You can delegate destruction to a third party, if you do you usually get a certificate of
destruction, it's usually the only proof you get that the drives have been destroyed.
```
