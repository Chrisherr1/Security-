# Security Controls

![Security Controls](<1.1 Security Controls.png>)

### Assets are varied

```text
- Data,Physical Property,Computer Systems
```

### Goal

```text
- Prevent Security Events
- Minimize the impact
- limit the damage
```

---

## Control Categories

### Technical controls

```text
- Controls Implemented using systems
- Operating system controls
- Firewalls, Anti Virus
```

### Managerial Controls

```text
- Administrative Controls
    Associated with Security Design and Implementation
- Security Policies
    Standard operating procedures
```

### Operational Controls

```text
- Controls implemented by people instead of systems
- Security guards && awareness programs
```

### Physical Controls

```text
- Limit Physical Access, Guard shack, Fence/locks, badge readers
```

---

## Control Types

```text
There can be different control types depending on the control category.
```

### Preventive

```text
- Block  access to a resource(Physical or digitally)
```

### Deterrent

```text
- Discourage an intrusion attempt
- Make an attacker think twice
- Does not directly prevent access
```

### Detective

```text
- Identify and log an intrusion attempt
- Basically have logs that tell you when people do anything
- may not prevent access
```

### Corrective

```text
- Apply a control after an event has been detected
- Correct the problem(Backups,policies, call cops)
```

### Compensating

```text
- Temporary
- Existing controls aren't enough
- Prevent the exploitation of a weakness
(Require simultaneous guard duties, Generator used after power outage)
```

### Directive

```text
- Weak
- Direct someone into security compliance
- 'Do this please'
```
