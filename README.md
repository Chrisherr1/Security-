# CompTIA Security+ (SY0-701) Study Notes

My personal study notes for the CompTIA Security+ SY0-701 exam, organized by exam domain and objective.

---

## Exam at a Glance

| | |
|---|---|
| **Exam** | CompTIA Security+ SY0-701 (released November 7, 2023) |
| **Time** | 90 minutes |
| **Questions** | Up to 90 (multiple choice + performance-based: matching, sorting, drag-and-drop) |
| **Passing score** | 750 on a scale of 100–900 |
| **Where** | Testing center or at home |

More in [Exam Expectations](Exam%20Expectations.md).
