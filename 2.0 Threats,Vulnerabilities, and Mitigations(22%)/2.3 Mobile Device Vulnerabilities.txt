---------------------------------
Mobile Device Vulnerabilities
---------------------------------

    Mobile Device Security

    - Very Challenging to secure
    - Relatively small
    - Always in motion
    - Packed with sensistive information
    - Constantly connected

    Jail Breaking/Rooting 
    
    - Mobile devices are purpose-built systems
        - You dont usually have access to the operating system 

    - Gaining access
        - Android - rooting
        - Apple OS - Jailbreaking

    - Install Custom firmware
        - Replaces the existing operating system
        - To surcumvent security

    - Sideloading
        - Malicious apps can be significant security concern.
            - One exploit can cause major security problems
            
        - Manage installation sources to prevent this.
            - local appstore

        - Sideloading circumvents security
            - apps can be installed manually without an app store
