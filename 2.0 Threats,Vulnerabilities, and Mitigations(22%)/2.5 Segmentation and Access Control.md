# Segmenting the network

```text
- Physical,logical, or virtual segmentation
- Performance
    - High- bandwidth applications
- Security
    - Users should not talk directly to database servers
    - The only applications in the core are SQL and ssh
- Compliance
    - Mandated segmentation
```

---

## Ways to implement

### Access Control lists(ACls)

```text
- Allow or disallow traffic
    - groupings of categories
    - source IP,destination Ip, port number, day of time
- restrict access to network devices
    - Limit by IP address or other identifiers
    - Prevent regular user / non-admin access
- Be careful when configuring these
    - You can end up locking yourself out

eg: Permissions
    different users may have different privileges on the network.

- many operating system use ACLs to provide access to files
```

### Application allow list / deny list

```text
- Blocking any application that isn't allowed to run
- allow list is better than deny list
- deny is more flexible tho.

eg: application hash, certificates,path,network zones
```
