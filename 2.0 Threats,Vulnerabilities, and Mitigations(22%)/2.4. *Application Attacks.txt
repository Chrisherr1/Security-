-------------------
Application Attacks
-------------------

    Injection Attacks
        - Basically where you inject code into a data stream
        - Usually enabled because of bad programming
            - The application should handle input and output properly
            - So many different injectable data types 
            - HTML,SQL,XL,LDAP,etc
    
    Buffer overflows

        - YOu add information into a particilar area in memory ment for 
        a variable but you're adding more information than that variable can 
        hold.

        - so the memory spills over to the next buffer

        - due to developers not preforming bounds checking
        - relatively diffuclt exploit
        -crashes the application usually

        - if attacker find a buffer overflow that is REPEATABLE.
        then now we have a problem 

    Replay Attack

        - some applications will allow an attacker to grab information from the 
        network directly or from the victim's computer and REPLAY that information
        to the server to gain addition access to the application.

        - Need access to the raw network data.
            - Network tap,ARP poisoning, malware on victim computer
        
        - The gathered information may help the attacker
            - Replay the data to appear as someone else.

        this is not an on-path attack

    
    privilege escalation

        - Gain higher level acces to a system 
        - might be a bug or design flaw

        - higher-level access means more capabilities
        
        -common attack type
        - high priority

        - horizontal privilege escalation
             user A can access user B resources

    Mitigating privilege escalation

        - Patch quickly
            - fix vulnerabilities
        - Updated anti virus / anti-malware software
            - block known vulnerabilities
        - Data Execution Prevention
            - only data in executable areas can run
        - Address space layout randomization
            - prevent a buffer overrunn on a specifc memory


    Cross-site requests
        - Cross-site requests are common and legitimate.
        - Most of them are unauthenticated requests

    Cross-site request forgery

        - One-click attack,session riding
        -CSRF,XSRF
        -Take advantage of the trust that a web application has for the user.
            - The website trusts your browser
            - Requests are made wtihout your consent or knowledge
        
        - Significant web application development oversight.

    Directory traversal
        - It is a vuln that has to do with a web server configuration.

        - Allow attacker to read files from a web server that are outside 
        the website's file directory.
        - Users shouldn't be able to browse the Windows directories or Linux 
        directories.

        -Web server software vulnerability
            - Won't stop users from browsing past the web server root

        - web application code vulnerability
            - takes advantage of badly written code.
