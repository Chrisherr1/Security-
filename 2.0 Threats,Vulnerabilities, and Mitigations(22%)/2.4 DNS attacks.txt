DNS Attacks
--------------------------------

    DNS poisoning
    ----------------
        - Modify the DNS server
        - Modify the client host file
            - The host file takes precedent over DNS queries
        
        The gist:
        send a fake response to a valid DNS request
            - requires a redirection of the original request or the resulting response
            - real-time redirection
            - On-path attack

    Domain hijacking
    ----------------
        - Get access to the domain registration,
        and you have control where the traffic flows.
            - You don't need to touch the actual servers
            - Determins the DNS names and DNS IP addresses
        
        Tries to get access of where the domain stuff is being managed that being
        where the domain was bought or wherever.

    URL hijacking
    ----------------
        - redirect a user to advertising
        - sell a badly spelled domain to the actual owner
        - try to redirect to th competitor
        - Phishing site
        - Inject with a drive-by-download
